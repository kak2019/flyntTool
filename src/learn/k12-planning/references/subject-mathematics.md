# 数学课程设计

## 核心原则

1. 围绕数学核心素养设计：数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识/能力、模型意识/观念、数据意识/观念、应用意识、创新意识等按学段选择。
2. 先分析概念结构和学生已有经验，再设计例题；不把“会套公式”当作理解。
3. 让学生经历观察、猜想、表示、计算、推理、验证、应用和反思中的适当过程。
4. 一组任务覆盖概念的关键变式、易混边界和最难结构，不只换数字重复。
5. 至少提供一种与概念匹配的表示：实物、图形、数轴、表格、统计图、方程、函数图像或几何图。

## 学段建议

- 小学：从真实或可理解情境进入，经历具体—图示—符号；重视算理、估算和表达。
- 初中：在数与代数、图形与几何、统计与概率、综合与实践之间建立联系；证明和模型逐步显性化。
- 高中：突出抽象、逻辑推理、数学建模、直观想象、数学运算和数据分析；概念形成先于题型套路。

## 课堂结构

建议使用：问题情境 → 独立尝试 → 多种表示/方法比较 → 概念或方法抽象 → 变式应用 → 课堂检测。不要机械照搬境外课程例程名称。

## 任务与评价

- 先列出本课概念的关键结构性情形，再把每种情形落实到学生必做任务。
- 课堂检测使用新数字或新情境，检验是否能独立选择表示和说明理由。
- 错误预判写成“具体错误表现—产生原因—教师追问/再任务”。
- 所有答案、图表数据、单位和计算必须实际验算。

## 作业

控制总量，建议由“基础巩固 + 变式辨析 + 开放应用”组成。不同层任务保持同一核心目标，不用大量重复计算代替思维。
