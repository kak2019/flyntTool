# 信息科技、劳动、艺术、体育与健康课程设计

具体核心素养名称和内容要求以教师提供的现行课程标准为准。

## 信息科技 / 信息技术

- 围绕信息意识、计算思维、数字化学习与创新、信息社会责任组织任务。
- 让学生分析问题、表示数据或流程、设计与调试作品、评价信息与数字工具。
- 不把课程做成软件按钮操作说明；工具选择服务于问题解决。
- 涉及网络信息时检查来源、隐私、版权、算法影响和安全。
- 无设备或设备不足时提供纸笔算法、流程图、数据表示或轮换方案。

## 劳动

- 让学生经历任务规划、规范操作、质量检查、改进和反思。
- 明确工具、材料、场地、卫生和安全要求；危险工具由教师或具备条件的人员处理。
- 成果评价兼顾劳动观念、过程能力、习惯品质和劳动精神，不只看成品是否漂亮。
- 任务应适龄、可在学校或家庭真实完成，不把家长代做计入学生成果。

## 艺术

- 围绕审美感知、艺术表现、创意实践和文化理解组织学习。
- 学生需要观看/聆听、分析、尝试、创作、展示和回应，不用艺术史讲授替代艺术实践。
- 范例用于观察技法和表达选择，不要求机械临摹成同一结果。
- 引用作品标明作者、作品名与来源；使用音视频和图片时遵守版权。

## 体育与健康

- 围绕运动能力、健康行为和体育品德组织学习。
- 写清动作目标、场地布置、器材数量、练习密度、分组轮换和安全距离。
- 提供降低冲击、改变距离/器材或替代动作等参与路径，但保持同一技能目标。
- 包含准备活动、主要练习、比赛/应用、整理放松和健康反思。
- 对疾病、伤情或残障学生的调整以学校健康信息和专业建议为准，不作医学诊断。

## 共同评价

使用过程性证据：操作表现、作品、练习记录、同伴反馈、自我检查和改进说明。评价标准应让学生事先看得懂，并允许通过不同成果形式展示达成。
